## 1. 제한 사항 · 요구사항 · 해결방안

### 1.1 하드웨어 제한

| 제한 사항 | 해결방안 |
|----------|---------|
| 14B 모델 FP16 ~12GB VRAM 요구 | GGUF 양자화 3종 (6.5 / 8.75 / 9.65GB) + `--lowvram` 순차 로드 |
| 텍스트 인코더(UMT5-XXL, 6.3GB)와 UNet 동시 상주 시 VRAM 초과 | `--lowvram` 인코딩 완료 후 UMT5-XXL → CPU 오프로드, GPU를 UNet 전용 확보 |
| WAN 2.2 VAE 48ch ↔ WAN 2.1 VAE 16ch 비호환 | WAN 2.2 제거, WAN 2.1 VAE(16ch)로 통일 |
| 7회 재시도 반복 시 VRAM 누수 → OOM | 매 attempt 후 `gc.collect()` + WSL 스왑 확보 |
| 소형 이미지 업스케일 시 GPU 메모리 초과 | Real-ESRGAN 타일링 분할 처리. pixel_art는 CPU fallback |

### 1.2 원본 원형 유지

> **요구사항**: 원본 이미지의 외형을 그대로 보존하면서 동작 애니메이션을 생성

| 문제 | 해결방안 |
|------|---------|
| img2img 방식은 포즈마다 외형 변형 → 정체성 유지 불가 | I2V 전환 — 원본 1장 → 비디오 → 프레임 추출. CLIP Vision 임베딩이 정체성 고정 |
| 소형 이미지 단순 리사이즈 → 디테일 소실 | Real-ESRGAN 4x AI 초해상도 업스케일 후 캔버스 배치 |
| flood-fill 배경 제거 → 흰 오브젝트 구분 불가 | rembg U2Net 시맨틱 세그멘테이션으로 색상 무관 분리 |
| WAN 480×480 고정 출력 ≠ 원본 크기 | 원본 크기 자동 감지 → Lottie 리사이즈 |
| 첫 프레임 bbox만 크롭 → 모션 중 잘림 | 전체 프레임 union bbox 크롭 |

### 1.3 동작 애니메이션 품질 확보

> **요구사항**: 자연스러운 모션 + 이미지 특성에 맞는 동작 + 웹 배포 품질

**사전 분류** — 강체는 GPU 낭비 없이 CPU 키프레임 엔진으로 즉시 처리 (Stage 1 KEYFRAME_ONLY)

**파라미터 자유 결정** — Gemini Vision이 프리셋 없이 액션·프롬프트·fps·검증 임계값을 이미지마다 직접 판단

**이중 검증으로 품질 필터링**

| 단계 | 내용 |
|------|------|
| 1차: 수치 검증 | 9항목 자동 체크 — 정지·과속·고스팅·프레임 이탈 등 객관적 품질 미달 필터링 |
| 2차: AI 검증 | Gemini Vision이 원본 + 5프레임(0/25/50/75/100%) 비교하여 주관적 품질 판단 |

**실패 시 자동 보정** — AI가 fps·scale·프롬프트 수정안을 직접 결정. 연속 3회 실패 시 액션 자체를 전환

**누적 학습** — 매 시도의 실패 로그(`validation_stats.txt`)를 저장하고, 다음 생성 시 실패 패턴 기반으로 negative 프롬프트를 자동 강화 → 시도할수록 품질 상승

**웹 배포 최적화** — 48fps 업샘플링(×3 정수배) + 캔버스 4x 확장(잘림 방지)

### 2.2 외부 의존성 매핑

```
AnimateOrchestrator (Application Layer)
        │
        │  포트 인터페이스(Protocol)만 참조
        │
        ├──→ Gemini API (Cloud)
        │      ├─ VisionAnalysisPort      ─→ gemini_vision_analyzer.py
        │      ├─ AIValidationPort        ─→ gemini_ai_validator.py
        │      └─ PostMotionClassification ─→ gemini_post_motion.py
        │
        ├──→ ComfyUI Server (localhost:8188)
        │      └─ AnimationGenerationPort ─→ comfyui_wan_generator.py
        │         └─ WAN 2.1 I2V-14B GGUF (Q3/Q4_S/Q4_M)
        │            + UMT5-XXL (텍스트 인코더)
        │            + CLIP Vision H (정체성 보존)
        │            + WAN 2.1 VAE (16ch 디코더)
        │
        ├──→ spandrel (로컬 GPU)
        │      └─ ImageUpscalerPort       ─→ spandrel_upscaler.py
        │         └─ Real-ESRGAN 4x
        │
        ├──→ rembg + onnxruntime (로컬 CPU)
        │      └─ BackgroundRemovalPort   ─→ bg_remover.py
        │         └─ U2Net
        │
        └──→ PIL / ffmpeg (로컬 CPU)
               ├─ MaskGenerationPort      ─→ mask_generator.py
               ├─ FormatConversionPort    ─→ format_converter.py
               └─ AnimationValidationPort ─→ numerical_validator.py
```
