# Git 그래프 노란색 경로 원인

**작성일**: 2026-03-21

## 현상

IDE Git 그래프에서 노란색 분기 경로가 표시됨.

## 원인

`c366fbb` merge commit 발생.

로컬에서 `2c1fdc4` 커밋 후 push 시, 리모트에 이미 다른 커밋 2개(`3fa2dec`, `40746f0`)가 존재하여 push 거부됨. `git pull`로 병합하면서 두 갈래 이력이 생성.

```
로컬:   345ade1 → 2c1fdc4 ─────────┐
리모트: 345ade1 → 3fa2dec → 40746f0 ┤ → c366fbb (merge)
```

## 영향

- 기능상 문제 없음
- 이력이 일직선이 아닌 분기 형태로 표시될 뿐

## 향후 방지

push 전에 `git pull --rebase`를 사용하면 merge commit 없이 일직선 이력 유지 가능.
